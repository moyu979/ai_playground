# 第 08 课 · 语言模型 — bigram → MLP → RNN

> 🌐 配套互动网页：[08_lm.html](../pages/08_lm.html)（讲解精华 + 可玩 demo，无需任何安装）


> 从这一课起，我们切换到 **生成模型**：不再"图片→标签"，而是
> "前文 → 下一个字符的概率分布"。这是 GPT 的核心任务，只是它做得更深更大。
> 本课终点你会得到一个会写"伪莎士比亚"的字符级 RNN——并看清它的三个致命伤，
> 它们正是第 9 课注意力机制要解决的问题。

## 1. 语言建模：下一个 token

一段文本 $x_{1:T} = (x_1, x_2, \dots, x_T)$ 的概率用链式法则分解：

$$p(x_{1:T}) = \prod_{t=1}^{T} p(x_t \mid x_{<t})$$

**语言模型 = 学会条件分布 $p(x_t \mid x_{<t})$。** 生成时从左往右采样，一次一个。

> **字符级还是词级？** 词级词表大（5 万+）且遇到没见过的词就懵（OOV）；
> 字符级词表小（本文语料 65 个字符）且永不 OOV，但序列长。
> 教学选字符级；工业界用 BPE 子词（karpathy 有专门一讲：*Let's build the GPT Tokenizer*）。

**评估指标**：训练目标是最小化平均负对数似然（就是第 3 课的交叉熵！）：

$$L = -\frac{1}{T}\sum_t \log p(x_t \mid x_{<t}), \qquad \text{困惑度} = e^{L}$$

困惑度的物理直觉：模型每一步在"多宽"的有效分布里犹豫。均匀 65 选 1 → 困惑度 65；
完美的下一个字符 → 困惑度 1。

## 2. bigram：数数就能建模型

只看前 1 个字符：$p(x_t|x_{t-1}) = \dfrac{N(x_{t-1}, x_t)}{N(x_{t-1})}$，
全部信息装进一张 $V\times V$ 计数矩阵。

- 好处：不用训练、一眼看穿（代码画了热图：`e` 后面常跟什么？）
- 坏处：上下文只有 1 个字符 —— 模型连 `th` 后该是元音都"不知道"，只知道单步统计
- 训练集困惑度 ≈ 5~7（names 数据）；任何能利用更长上下文的模型都应碾压它——**这就是基线**

## 3. 神经网络语言模型（Bengio 2003）：embedding 登场

上下文取前 $n$ 个字符，架构：

```
(context 字符索引) → 查表 C[V, d] 得 d 维向量 ×n → 拼接 → MLP → softmax(V)
```

关键新概念 **embedding（嵌入）**：把离散符号映射成可学习的低维向量。
"字符 'a' 是什么"不再由它在词表里的序号决定，而由它在 $d$ 维空间中的**位置**决定——
用法相近的字符会自动靠拢（代码画了 2D 嵌入散点：注意元音们抱团的现象）。

这解决了 bigram 的"上下文长度=1"，但拼接定长窗口仍是**扁平**的：
换个上下文长度就得换网络。

## 4. RNN：把"读过的"压缩进一个状态

循环神经网络用同一个单元递归地处理序列：

$$h_t = \tanh(W_{xh}\, x_t + W_{hh}\, h_{t-1} + b), \qquad \text{logits}_t = W_{hy} h_t$$

- $h_t \in \mathbb R^{d_h}$ 是**隐状态**：整段历史的有损压缩（像系统状态变量）
- 同一组权重用 $T$ 次 → 天然处理任意长度、参数量与序列长度无关
- 训练用 **BPTT**（沿时间反传）：把 RNN 展开成深度为 $T$ 的网络，autograd 自动搞定

> **梯度消失的物理本质**：反传经过时间维度要连乘雅可比
> $\dfrac{\partial h_t}{\partial h_{t-1}} = D\,\odot\, W_{hh}^T$（$D$ 是 tanh 导数的对角阵）。
> 乘性动力学的行为由谱半径决定——和迭代映射的 **Lyapunov 指数**同一套数学：
> $\|W_{hh}\|$ 略小于 1 → 信号/梯度指数衰减（第 1 步的教训传不到第 50 步）；
> 略大于 1 → 爆炸（训练用梯度裁剪急救）。**代码用 hook 实测了 $\|\partial L/\partial h_t\|$ 随 $t$ 的衰减曲线。**

**LSTM/GRU**（1997/2014）：给状态加"门控"——一个[0,1]的乘性阀门
$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$，让信息可以**近似恒等**地流过时间
（加法路径 vs 乘法路径）。理解思想即可，用 `nn.LSTM`。
> 埋个伏笔：这种"加法高速公路"在 ResNet 残差连接里会再次登场（第 10 课 Block）。

## 5. RNN 的三个根本痛点（第 9 课的引子）

1. **顺序计算**：$t$ 步必须等 $t-1$ 步，无法并行 —— GPU 大部分算力在围观
2. **长程依赖衰减**：即使 LSTM，信息也要一步步"搬运"，距离 $O(T)$
3. **信息瓶颈**：任意长的历史压缩进固定维的 $h$，是个有损单通道

解法预告：让每个位置**直接**访问所有历史位置——按"相关性"加权取用。
这就是注意力。
