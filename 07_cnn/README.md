# 第 07 课 · 卷积神经网络 — 把对称性写进架构

> 🌐 配套互动网页：[07_cnn.html](../pages/07_cnn.html)（讲解精华 + 可玩 demo，无需任何安装）


> 物理视角：**对称性 → 守恒/不变性 → 简化描述**，这条 Noether 式的逻辑链在
> 深度学习里的对应物是：**数据有平移对称性 → 特征检测器不应依赖位置 → 权重共享（卷积）**。
> 你在信号与系统里学的卷积 $y(t) = \int h(\tau)x(t-\tau)d\tau$ 就是同一操作——
> 核 $h$ 是系统的脉冲响应，图像卷积里它是"特征检测器"。

## 1. MLP 处理图像的两个浪费

把 28×28 图像摊平成 784 维向量喂给 MLP：
- **参数爆炸且无结构**：第一层 784×128 ≈ 10 万参数，每个参数只见过一个孤立像素——
  但自然图像的统计规律（边缘、纹理）是**空间局部**的
- **无平移不变性**：猫在左上角和右下角需要分别学两遍

## 2. 卷积：三个思想合一

对图像 $X$ 和小核 $K$（比如 3×3），卷积输出：

$$Y_{ij} = \sum_{a}\sum_{b} K_{ab}\, X_{i+a,\, j+b}$$

（严格数学卷积还要翻转 $K$；深度学习省略翻转，即**互相关**——核是学出来的，
翻转约定无关紧要。）

1. **局部连接**：每个输出只看 3×3 邻域（图像统计是局部的）
2. **权重共享**：同一个 $K$ 扫过全图 —— 10 万参数变 9 个！
   平移一个特征检测器 = 用同一组权重
3. **平移等变性**：输入平移 → 特征图平移。再配 pooling/全局聚合 → 平移**不变**性

> 验证参数直觉：$K$ 是 3×3×$C_{in}$（对每个输入通道一份）+ 每输出通道一个偏置。
> 卷积层参数量 = $K_h K_w C_{in} C_{out} + C_{out}$，与图像大小无关。

## 3. 多通道与层次结构

- 输入图像本身是多通道的（灰度 1 通道 / RGB 3 通道）
- 每个卷积层输出 $C_{out}$ 张"特征图"（feature map）——每个通道是一种特征检测器
- **层次化**：第一层学边缘/条纹（Gabor 感），第二层学角/纹理块，
  更深层学部件→物体。这与视觉皮层 V1→V4→IT 的层级惊人相似
- 感受野（receptive field）随层数指数增长：两层 3×3 看到互补重叠的 5×5，
  这就是"深比宽高效"的机制之一

## 4. 空间下采样

池化（2×2 max pooling）把每 2×2 区域取最大值：特征图尺寸减半，
小幅平移不再改变输出（不变性），计算量减半。现代替代方案：**stride=2 的卷积**
（下采样本身也可学习），练习 3 让你实测两者。

## 5. MNIST：手写数字识别（深度学习的 "hello world"）

```
输入 (B,1,28,28)
  → Conv 3×3, 1→16  → ReLU → MaxPool 2×2   # 28→14, 学边缘笔画
  → Conv 3×3, 16→32 → ReLU → MaxPool 2×2   # 14→7,  学笔画组合
  → Flatten (32×7×7=1568) → Linear→128 → ReLU
  → Linear→10                              # 每类一个 logit
```

~22 万参数，3 个 epoch 后测试准确率 ≈ **99%**。
对比：第 4 课的 MLP 直接摊平也能到 ~97%——卷积的 2 个点来自**结构先验**。

> **对照实验**（`mlp_vs_cnn.py`，同数据同预算）：摊平 MLP 用 101,770 参数到 91.4%，
> 小 CNN 用 **9,098 参数**（1/11）到 **94.4%**。参数更少、精度更高——
> 这就是把对称性写进架构的直接回报。
