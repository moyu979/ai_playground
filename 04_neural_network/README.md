# 第 04 课 · 神经网络与反向传播 — 用纯 NumPy 造出"学习机器"

> 物理视角：反向传播 = **伴随方法**（adjoint method）。
> 优化由动力学约束的泛函时，你定义伴随变量从终端条件往回扫——
> 神经网络的"逐层反传"就是同一件事：$z$ 是正问题（forward），$\delta$ 是伴随变量（backward）。
> 本课是整个课程的枢纽：读慢一点，推导亲手过一遍。

## 1. 为什么需要隐藏层

第 3 课的决策边界是线性的。看下图两类数据（运行 `train_toy.py` 你会得到它们）：

```
双月形:  ○○○○○           螺旋形:  ● ● ●
        ○○○○○  ○                ●  ● ●
         ●●●●● ●                ● ● ●
          ●●●●                 ●  ●  ●
```

无论怎么调 $w, b$，一条直线都切不开它们。**需要的不是更好的直线，是弯的边界。**

两条路：
- 特征工程：手工加 $x_1^2, x_1x_2$ 等特征（核方法的老路）
- **让网络自己长出特征**：中间塞一层非线性变换——这就是隐藏层

## 2. 结构与前向传播

一个两层网络（1 个隐藏层），行向量记号（batch 友好，代码即公式）：

$$X \xrightarrow{\;W^{(1)},\,b^{(1)}\;} z^{(1)} \xrightarrow{\;\phi\;} a^{(1)}
\xrightarrow{\;W^{(2)},\,b^{(2)}\;} z^{(2)} \xrightarrow{\;\text{softmax}\;} P$$

| 张量 | 形状 | 含义 |
|---|---|---|
| $X$ | $(B, d_{in})$ | batch 输入，B 个样本 |
| $W^{(l)}$ | $(d_{l-1}, d_l)$ | 第 $l$ 层权重（输入维 → 输出维） |
| $z^{(l)} = a^{(l-1)}W^{(l)} + b^{(l)}$ | $(B, d_l)$ | 预激活 |
| $a^{(l)} = \phi(z^{(l)})$ | $(B, d_l)$ | 激活（$\phi$: tanh / ReLU） |
| $P = \text{softmax}(z^{(L)})$ | $(B, K)$ | 每类概率 |

激活函数必须非线性——否则两层线性变换会塌缩成一层
（$a_1 W_2 = x W_1 W_2 = x W'$，网络退化为第 2 课的线性回归！）。

常用激活：$\tanh(z) \in (-1,1)$，$\text{ReLU}(z) = \max(0, z)$。
后者是现代默认：正区梯度恒为 1，多层不衰减。

> **万能近似定理**（一句话版）：单隐藏层、足够宽、+温和条件的网络可以以任意精度
> 逼近任意连续函数。"宽"可以买，"深"更高效——这是后面 CNN/ResNet 的伏笔。

## 3. 损失与输出层（第 3 课的全部遗产）

softmax + 交叉熵，梯度塌缩成一行：

$$L = -\frac1B \sum_{i,k} Y_{ik}\log P_{ik}
\quad\xrightarrow{\ \partial L/\partial z^{(L)}\ }\quad
\delta^{(L)} = \frac{1}{B}\,(P - Y)$$

## 4. 反向传播：四个方程

**定义**（伴随变量）：
$\delta^{(l)} \equiv \dfrac{\partial L}{\partial z^{(l)}} \in \mathbb R^{B \times d_l}$
——损失对第 $l$ 层**预激活**的敏感度。已知 $\delta$，参数梯度是"顺手的"：

$$\boxed{\;\frac{\partial L}{\partial W^{(l)}} = (a^{(l-1)})^T \delta^{(l)},\qquad
\frac{\partial L}{\partial b^{(l)}} = \mathbb 1^T \delta^{(l)}\;}\tag{7, 8}$$

因为 $z^{(l)} = a^{(l-1)}W^{(l)} + b^{(l)}$ 里 $W^{(l)}_{jk}$ 只出现在 $z_j$ 处、系数 $a_k$。
（batch 维求和；代码里除以 $B$ 的因子已含在 $\delta^{(L)}$。）

**递推**——这是链式法则的矩阵化。$z^{(l+1)} = a^{(l)}W^{(l+1)} + b^{(l+1)}$，
$a^{(l)} = \phi(z^{(l)})$，于是：

$$\boxed{\;\delta^{(l)} = \big(\delta^{(l+1)} (W^{(l+1)})^T\big)\odot \phi'(z^{(l)})\;}\tag{6}$$

第一步矩阵乘把"下游各 $z^{(l+1)}$ 对我的敏感度"加权求和，第二步乘上本层激活的局部导数
（$\odot$ 是逐元素乘）。**输出层**就是公式 (4)：$\delta^{(L)} = (P-Y)/B$。

**全部算法**（代码 `mlp.py` 逐行对应）：

```
forward:  a⁰ = X;  对 l = 1..L:  zˡ = aˡ⁻¹Wˡ + bˡ;  aˡ = φ(zˡ)
backward: δᴸ = (P − Y)/B                         ← 输出层
          对 l = L..1 反向:  ∂L/∂Wˡ = (aˡ⁻¹)ᵀ δˡ;  ∂L/∂bˡ = 1ᵀδˡ
                             δˡ⁻¹ = (δˡ (Wˡ)ᵀ) ⊙ φ'(zˡ⁻¹)
update:   W ← W − η ∂L/∂W   (第 2 课的 SGD 原样复用)
```

> **形状检查 = 量纲分析。** 物理学家拿到公式先查量纲，你拿到反传代码先查形状：
> $(a^{(l-1)})^T\delta^{(l)}$ 是 $(d_{l-1},B)(B,d_l) = (d_{l-1},d_l)$ ✓ 和 $W^{(l)}$ 同形；
> $\delta^{(l+1)}(W^{(l+1)})^T$ 是 $(B,d_{l+1})(d_{l+1},d_l) = (B,d_l)$ ✓ 和 $\delta^{(l)}$ 同形。
> 形状不对的反传代码**一定**是错的——这能秒杀 90% 的手写 bug。

**为什么叫"反"向传播？** 前向一遍算出所有 $a^{(l)}$（缓存！），反向一遍算出所有 $\delta^{(l)}$。
总代价 ≈ 2 倍前向，而不是对每个参数做一次有限差分（代价 ≈ 参数个数倍前向，
千万参数 = 千万倍）——这就是自动微分存在的意义，第 5 课的主题。

## 5. 初始化：别让信号在第一层就死掉

若每层权重同分布、方差 $\sigma_w^2$，则激活方差近似按层传播：
$\mathrm{Var}(z^{(l)}) \approx (d\,\sigma_w^2)\,\mathrm{Var}(a^{(l-1)})$——
级联放大/衰减，像没有临界点的分支过程：

- $d\sigma_w^2 > 1$：逐层爆炸（tanh 很快饱和，梯度消失）
- $d\sigma_w^2 < 1$：逐层熄灭（网络死寂，学不动）
- **临界**：He 初始化 $\sigma_w = \sqrt{2/d_{in}}$（ReLU），Xavier $\sqrt{1/d_{in}}$（tanh）

全零初始化更糟：所有神经元对称，梯度也对称，**永远学成同一个东西**（对称性自发破缺失败）。练习 2 会让你看到三种初始化的命运。

## 预告

本课手推梯度爽吗？累。每改一个结构就要重推一遍，而且推导易错、检查靠数值梯度。
第 5 课我们造**自动微分引擎**：每个运算只管自己的局部导数，链式法则由机器执行——
这就是 PyTorch `autograd` 的核心思想（Karpathy micrograd 同款，~100 行）。
