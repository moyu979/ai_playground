04 · 神经网络与反向传播

四个方程走天下。反向传播 = 伴随方法：z 是正问题，δ 是伴随变量。

🎯 四个方程（课程枢纽，值得背下来）

#公式 (batch, 行向量记号)一句话
(4)δ(L) = (P − Y)/B输出层：又是"预测减标签"
(6)δ(l) = (δ(l+1)(W(l+1))ᵀ) ⊙ φ'(a(l))矩阵乘收敏感度 ⊙ 本层导数
(7)∂L/∂W(l) = (a(l−1))ᵀ δ(l)输入在外、δ 在内
(8)∂L/∂b(l) = 𝟙ᵀδ(l)δ 按样本求和

🧪 形状检查 = 量纲分析：每一步都检查矩阵形状，形状不对的代码一定是错的。

# ---- 反向 (mlp.py::loss_and_grad, 逐行对应上表) ----
Y = np.eye(P.shape[1])[y]
delta = (P - Y) / B                       # 公式 (4): δ^L = (P−Y)/B
for layer in reversed(self.layers):
    delta = layer.backward(delta)         # 公式 (6)(7)(8) 逐层执行

# Dense.backward 内部:
self.dW = self._x.T @ dz                  # (7): (a^{l-1})^T δ^l
self.db = dz.sum(axis=0)                  # (8): 1^T δ^l
return dz @ self.W.T                     # (6) 前半: δ^l (W^l)^T

# Activation.backward 内部 (tanh):
return da * (1.0 - self._a**2)            # (6) 后半: ⊙ φ'(z)
