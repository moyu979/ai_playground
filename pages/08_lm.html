08 · 语言模型：bigram → RNN

p(xt | x<t) —— GPT 的核心任务，先从"数数"开始。

🎯 本课在讲什么

语言模型 = 学会下一个字符的条件分布。评估指标: 交叉熵 L， 困惑度 = eL（模型每步在"多宽"的分布里犹豫）。 本页是一个真的 bigram 模型: 统计 160 个名字的字符共现矩阵， 然后从里面采样。终端课里你会把它升级成 embedding+MLP（困惑度 11.6→8.8） 和 RNN（→2.1），最后在第 10 课变成 GPT。

🧪 动手玩：bigram 计数矩阵 + 采样

计数矩阵 (行=当前字符, 列=下一个; 点一下选行)
下一字符分布 (当前行 .) · 温度 T = 玻尔兹曼温度
点「采样」试试 — T→0 刻板复读, T→∞ 疯癫乱码

训练集困惑度: — (均匀分布参考: 27) · 你选中的行会高亮。第一行 '.' 就是"名字怎么开头"的分布。

🧪 去终端做真练习

cd 08_sequence_models && python bigram.py（3.2 万名字 + 莎士比亚 bigram）， python mlp_lm.py（embedding 登场, 2D 嵌入散点看元音抱团）， python rnn_char.py（字符级 RNN 写伪莎士比亚 + 梯度消失实测）， python exercises.py。讲解: README.md
