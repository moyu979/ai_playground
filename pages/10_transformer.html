10 · Transformer (GPT)

把前 9 课的零件组装成 nanoGPT —— 然后训练它写莎士比亚。

🏗️ GPT 全家福 (悬停看每个零件去哪了)

token + 位置 embedding tok_emb (V×d) + pos_emb (T×d) · model.py::GPT.__init__
↓ × N 层 (本课 N=4)
x = x + Attn(LN₁(x)) 残差 + pre-LN + 多头因果注意力 · CausalSelfAttention
↓
x = x + MLP(LN₂(x)) 残差 + 4 倍升维 · MLP / Block
↓
LN → Linear(d→V) 输出每个位置的下一 token 分布 · lm_head
↓
softmax → 交叉熵 / 采样 训练 targets 右移一位 · generate()

⚙️ 训练配置: 4 层/4 头/128 维/block 64 ≈ 80 万参数, AdamW(β=0.9,0.95), 梯度裁剪 1.0, MPS 上 2000 步 ≈ 2 分钟 → 困惑度 6.0。GPT-2 与它的区别只有数字。

🧪 动手玩：采样参数模拟器 (generate() 的心脏)

模型输出 8 个候选 token 的 logits。拖动温度(玻尔兹曼 T!)、 top-k, 看分布怎么变形，再采样。

采样历史会显示在这里 — T→0 几乎永远同一个, T=2 接近乱选

原始 logits: cat 2.2 · sat 1.8 · the 1.5 · mat 1.2 · on 0.9 · a 0.5 · queen 0.2 · dog −0.8
🧪 试一试: T=0.1 + k=1 → 贪心复读机; T=2 + k=8 → 醉汉; T=0.8 + k=3 → 教科书推荐配置

🧪 去终端做真的训练 (毕业战)

cd 10_transformer && python model.py（自检: 形状+因果性）→ python train.py（训练 + 生成伪莎士比亚, 已有我的训练结果可对照）→ python ablation.py（反面教材: 拆掉残差/位置编码的对照实验）→ python exercises.py（top-p / 手写 GELU / warmup+cosine 调度器）。
毕业挑战: python train.py --n-layer 6 --n-embd 384 过夜训练； 把 data/shakespeare.txt 换成中文小说（字符级 tokenizer 天然支持）。
